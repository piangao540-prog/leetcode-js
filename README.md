# leetcode-js

我的 LeetCode 刷题记录(秋招冲刺版 · 前端)。

## 怎么用

- 每天点链接去 LeetCode 做题,做完把代码贴进对应题目的 `index.js`,补上「思路」和「复杂度」,再回来把 README 里的勾打上。
- 每天开始新题前,先看一遍昨天做错的题。
